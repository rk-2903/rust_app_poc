# rust_app_poc

Dioxus 0.7 mobile app (Rust). See [README.md](README.md) for the product
roadmap and phases.

## Conventions

Before adding or restructuring any code under `app/src`, follow the
[dioxus-conventions](.claude/skills/dioxus-conventions/SKILL.md) skill —
naming, folder structure (`components/`, `views/`, `audio/`,
`transcription/`), and Dioxus 0.7 component/state rules. Load it with
`/dioxus-conventions` or the Skill tool before writing Dioxus code.
